# 高考语文真题获取打法

## 源站优先级（实测结论）

| 源站 | 定位 | 2026 可得性 |
|---|---|---|
| **新都网** `edu.newdu.com` | **最佳文字源**（全国卷） | 全国Ⅰ/Ⅱ卷完整文字版 |
| 官方考试院 `shmeea.edu.cn` / `bjeea.cn` / `zhaokao.net` | **权威评析**（自主命题卷替代） | 有评析，无真题卷面 |
| 中国教育在线 `gaokao.eol.cn` | 网页版，更新慢 | 停留 2025，标"持续更新中" |
| 第一试卷网 `shijuan1.com` | rar 打包，免登录 | 止于 2025 |
| 无忧考网 `51test.net` | 2026 有全套**图片版** | 仅全国卷省份，独缺京津沪 |

## 新都网抓取要点（最常用）

- **URL 规律**：`/NECE/{学科}/{栏目}/{YYYYMM}/{ID}.html`
  - 例：`/NECE/Chinese/Analysis/202606/4928959.html`（学科 Chinese=语文，栏目 Analysis=试卷评析/真题）
  - 频道首页 `/NECE/Chinese/Index.html` 下钻子栏目；`/NECE/Chinese/OldExam/Index.html` 历年真题
- **ID 全局递增**，同年高考卷集中成段（2026：4928953 作文范文 / 4928959 全国Ⅰ卷 / 4928960 全国Ⅱ卷 / 4928961-62 英语）。**扫描 ID 邻域是定位新卷的最快方法**。
- **分页**：`/ID.html` 是首页，后续 `/ID_2.html` … `/ID_N.html`；分页条在 `<div class='list-pager-turn'>`，正则 `href='(\d+_\d+\.html|\d+\.html)'`
- **编码 GBK/GB18030**（先试 utf-8 再 gb18030）
- **正文纯文本 + `<BR>` 换行**，含试题、答案、解析；正文区 `class="detail-text"`
- **站内搜索不可用**：`search.asp?keyword=` 按日期排序返回最新文章，关键词不生效 → 必须靠频道页逐级下钻

## 自主命题卷（北京/天津/上海）现实

**官方不公开电子版**，免费源基本没有完整卷面。可获取的是：
1. **官方评析**（考试院发布，含考点/素材/命题意图，权威够用）
2. 作文题原文（人民网/央视网每年 6/7 即时发布）
3. 付费源：学科网 `zujuan.xkw.com`、书刊网 `max.book118.com`（有完整卷面，需账号/积分）

### 🎯 上海卷重大突破：gaokao.cn 静态 CDN 有图片版真题（2026 实测可用）

```
https://static-gkcx.gaokao.cn/upload/zhenti/{YYYYMMDD}/{uploadId}_{seq}.pdf
```
- 实例：`https://static-gkcx.gaokao.cn/upload/zhenti/20260608/1780882760_4457.pdf` = **2026 上海语文卷真题（8 页图片版）**
- `_4457` 这个 seq 是**该文档专属**，邻域探测（4456/4458/4459…）全 404 → 不能靠改 seq 找其他卷
- **PDF 无文字层**（扫描件），需提取内嵌图片：
  ```python
  # 先 pip install "pypdf[image]"
  from pypdf import PdfReader
  r = PdfReader(pdf)
  for i, p in enumerate(r.pages):
      imgs = list(p.images)
      best = max(imgs, key=lambda x: len(x.data))  # 每页有多图，取最大
      open(f'p{i+1}.jpg','wb').write(best.data)
  ```
- 该 PDF 会出现在搜索结果里（`site:gaokao.cn 2026 上海语文卷 高考真题 pdf`），搜到直接下

### 天津卷现实（2026 实测）
- **完整卷面仍未公开**。教习网天津真题列表确认只有"作文深度点评讲义"，无完整卷面
- **但官方评析信息量极大**，含**具体题号级考点信息**：
  - 天津：北方网 `news.enorth.com.cn/system/2026/06/07/059468312.shtml`；
    干净 UTF-8 转载：津东方 `luozaitianjin.com/edu/k12/yw/{id}.html`
  - 评析会点名：文言文出处（梁启超《万木草堂小学学记》）、文学类文本篇名（周闻道《杜鹃不语》）、信息类主题（"词元"）、以及第13/14/20/21/23题的具体考法
- **文学类文本可反向溯源**：搜"《篇名》 高考 出处 作者"常能找到作者自述/期刊公众号，拿到原文与首发信息

## ⚠️ 预览图 OSS 桶会串库（新踩的坑）

教习网预览图规律 `jx-previews-01.oss-cn-hangzhou.aliyuncs.com/3/2/{docId}/0/{n}.jpg` **可以访问**，但：
- 同一 docId 目录下 n 递增会**串到完全无关的其他文档**（实测下载 2026 上海卷，n=1 得到的是 2021 上海卷）
- **教训：用 OSS 预览规律批量下载，必须逐页目视核验，不能假定连续编号属于同一文档**

## 作文题多源交叉（2026 实测）

- **中国青年网** `news.youth.cn/jsxw/2026{MM}/t2026{MMDD}_{id}.htm` → 发布《2026年高考语文作文试题》，含全国Ⅰ/Ⅱ/北京/天津/上海**五套作文原题全文**（权威，教育部教育考试院口径）
- **中工网** `workercn.cn` 常转载考试院撰写的官方命题设计思路
- **百度百科**有单卷权威词条（如 `2026年上海高考语文试卷`=67962128），考点全貌详实，可与图片版真题交叉验证

## ⚠️ 内容层核验（必须做，不可省）

**不做"HTTP 200 即成功"的粗口径。** 核验四项：
- 魔术字节（.doc=`D0CF11E0`、.docx/rar=`PK`、.pdf=`%PDF`、.png=`89504E47`）
- 内部结构（rar 内部文件名、docx 内部 XML）
- 年份卷种比对（标题里的年份/卷种要与目标一致）
- 文本层：有试题（正则 `阅读…完成|下列对`）、有答案（`【答案】|参考答案`）、有解析（`【解析】|【详解】|故选`）

**大坑**：搜索引擎里标着"20XX年高考语文〔北京/天津/上海〕卷真题"的页面，**大量是 AI 编造的模拟题**。判据：
- 题号编到 40+（真实高考卷不超 25 题）
- 题型混乱（如现代文阅读里塞进"顿号使用""句式变换"）
- 作文材料与官方公布的不符
- 同一套卷的"试题"在不同页面自相矛盾
- **用初中课文冒充高考题**（如《使至塞上》《春望》《曹刿论战》《记承天寺夜游》）——高考不考初中课文作阅读材料
- **泛化编造篇名**（《在时间的褶皱里》《老槐树下的黄昏》），真实高考篇目通常可溯源到期刊/出版社
- **伪造史书引文**（编造《旧唐书·杜牧传》《宋书·范晔传》等不存在的段落）
- 每道题都配"标准 AI 解析口吻"的完整答案

**⚠️ 部分为真不等于整体为真**：2026 天津卷作文题（"调"字）在多个 AI 编造文件中**也正确出现**——编造者会混入真题材料来提升可信度。**必须逐题核验，不能因某一题是真的就采信整份文件**。

**遇到这类内容必须排除，绝不归档为真题**——否则教案会出现史实错误。

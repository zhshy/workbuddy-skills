# 阅读伴侣

帮助用户管理读书笔记：提取核心观点、跨书籍主题关联、生成复习卡片。

## 使用场景

- 用户说「帮我整理这本书的核心观点」「总结一下关键笔记」
- 用户说「这本书和上次那本有什么关联」「这个主题下我读过哪些书」
- 用户说「帮我做读书笔记的复习卡片」「推荐下一本读什么」

## 执行方式

直接使用模型能力分析和整理，读书笔记存储在本地文件中。若用户给出的是 PDF/EPUB 等电子书文件，先用 read-book 技能提取笔记，再回到本技能归档。

### 读书笔记模板

```markdown
# 《[书名]》读书笔记

**作者**: [作者名]
**阅读日期**: YYYY-MM-DD
**评分**: ⭐⭐⭐⭐ (4/5)

## 一句话总结
[用一句话概括这本书的核心]

## 核心观点 (Top 3-5)
1. [观点 1] — [简要解释]
2. [观点 2] — [简要解释]
3. [观点 3] — [简要解释]

## 金句摘录
> "[原文摘录]" — p.XX
> 我的理解：[个人思考]

## 实践行动
- [ ] [读完这本书我要做什么]

## 关联书籍
- 《[相关书名]》: [关联点]
```

### 笔记存储

```
~/Documents/reading-notes/
├── books/
│   ├── thinking-fast-and-slow.md
│   ├── mingzuo-xidu.md
│   └── ...
├── themes/
│   ├── 语文教学.md          # 主题汇总
│   └── 写作教学.md
└── flashcards/
    └── review-cards.md
```

（`~/Documents/reading-notes/` 即 `C:\Users\<用户名>\Documents\reading-notes\`，首次写入时自动创建目录结构。）

### 跨书籍主题关联

当用户读完多本书后，自动发现主题关联：

```markdown
## 主题: 写作教学

### 相关书籍
1. 《写作教学教什么》 — 过程指导重于结果要求
2. 《思辨读写十讲》 — 议论文的思辨训练
3. 《交际语境写作》 — 情境化任务写作

### 核心洞察
不同作者从不同角度论证了...

### 综合行动建议
结合多本书的建议，最有效的做法是...
```

### 复习卡片

```markdown
Q: 《写作教学教什么》对"写作过程指导"的核心主张是什么？
A: 写作教学重点在过程（构思、起草、修改）的策略指导，而非只针对成品的评分要求。

Q: 王荣生"先定教什么"的主张指什么？
A: 教学设计的第一步是确定合宜的教学内容；"教什么"错了，"怎么教"再好也无效。
```

## 输出规范

- 笔记保存到本地 `~/Documents/reading-notes/` 目录
- 核心观点精炼到 3-5 个
- 金句摘录标注页码或章节
- 复习卡片使用 Q/A 格式
- 主题关联至少涉及 2 本书
- 每新增一本书的笔记后，主动检查 `themes/` 目录：新书命中已有主题时更新对应主题页；出现新主题且已有 2 本以上相关书时，创建新主题页

# 各输出模式的模板

每种模式对应最终汇总 `notes.md` 的模板。每个章节块先产出同结构的局部笔记，最后汇总合并。

---

## notes（默认）

适合：读非虚构书并希望日后随时查阅。

### 单块模板

```markdown
### 第 N 章：<章节标题>

**TL;DR**：<2–3 句概括>

**核心概念**：
- **<概念>** — <一句话解释>
- **<概念>** — <一句话解释>
- （每章 3–7 条，不多于 7 条）

**值得保留的金句**：
> "<逐字引文>" (p. X)
> "<逐字引文>" (p. Y)

**行动项 / 启示**：
- <如果我相信这一章，我会在做法上有什么不同？>
- <可以尝试的事 / 可以做的实验>

**引入的框架**：
- **<框架名>**：<一句话概括其结构>

**存疑 / 不认同之处**：
- <我持保留意见或希望看到更多证据的地方>
```

### 全书汇总

```markdown
# 《<书名>》 <作者>

## TL;DR
<综合全书的 2–3 句>

## 关键要点
1. <要点>
2. <要点>
3. <要点>
（共 3–7 条——是"被遗忘后仍然幸存"的那些）

## 这本书适合谁
<一句话>

## 判断
<推荐读吗？跳读吗？与其他书如何搭配读？>

## 章节笔记
<所有单块输出依序拼接>

## 交叉引用建议
- 可关联《<已有笔记的书>》（依据第 X 章的……）

## 来源
- 文件：<路径>
- 作者：<作者>
- 页数：<页数>
- 阅读日期：<日期>
- 模式：notes
```

## summary

适合：时间紧、"我漏了什么重点"、见面前临时补课。

### 单遍模板（不做逐块汇总）

```markdown
# 《<书名>》 <作者> — 摘要

**TL;DR（一段话）**：<4–6 句>

**关键要点**：
1. <要点>
2. <要点>
3. <要点>
（共 3–5 条，不多于 5 条）

**这本书适合谁**：<一句话>

**要不要读全书？** <是 / 否 / 只读第 X、Y 章>

**来源**：<路径>，<作者>，<页数> 页，<日期>
```

超过 100 页的书，抽读处理（导言 + 2–3 个中间章 + 结尾），summary 模式不值得全量处理。

---

## quotes

适合：为讲座、写作、内容创作挖金句。

### 单块模板

```markdown
### 第 N 章：<章节标题>

> "<逐字引文>" — <若非作者本人则注出处> (p. X)
> "<逐字引文>" — (p. Y)
> "<逐字引文>" — (p. Z)

（金句密集的章节每章 5–15 条；稀疏的章节 0–3 条——只留真正值得摘的）
```

### 全书汇总

```markdown
# 《<书名>》 <作者> — 金句

<全部金句，按章节分组，带页码>

## 来源
- 文件：<路径>
- 阅读日期：<日期>
```

无分析、无评论——纯逐字引文。需要分析用 notes 模式。

---

## study

适合：深度学习、想长期记住的书、备课/讲座准备。

### 单块模板

notes 模式的输出，另加：

```markdown
**间隔重复问答**：
1. **问**：<检验核心概念记忆的问题>
   **答**：<1–2 句答案>
2. **问**：<问题>
   **答**：<答案>
（每章 2–4 组问答）
```

### 全书汇总

notes 模式的汇总，末尾另加：

```markdown
## 间隔重复卡组（完整版）

<所有章节的问答，按序排列，可直接导入 Anki/Mochi/RemNote>

## 建议复习节奏
- 第 1 周：每天过一遍全部问答
- 第 2–4 周：隔天复习
- 之后：标准 SRS 计划
```

问答格式使产出可直接导入间隔重复应用。用户需要 Anki 可导入的 TSV 时，加 `--anki` 参数（每行一个"问[TAB]答"）。

---

## 各模式通用注意事项

- **引文归属**：作者引用他人时，归属放在引文后（`—— 安迪·威尔金森`）；作者本人的话不需另注。
- **页码**：能拿到就一定标。EPUB 转换后没有稳定页码的，用"章 + 段"近似定位（`第3章 第12段`）。
- **框架**在 notes 模式下单独成条——记住一个框架，胜过记住十个会忘的点。
- **存疑/不认同**在 notes 模式下是必填项（有就必须写）。批判性阅读胜过仰视式阅读——把摩擦写出来。

## 渲染为 HTML（可选）

调用时带 `--render html` 参数时，用 pandoc 把最终 notes.md（或 summary.md / quotes.md / study.md）渲染成适合分享的文档。

```bash
# 一次性安装：winget install --id JohnMacFarlane.Pandoc
pandoc "<workdir>/notes.md" --standalone --metadata title="<书名>" -o "<workdir>/notes.html"
```

- 本机未装 pandoc 时：说明并跳过渲染，markdown 版本已经完整可用
- HTML 渲染后用浏览器打开即可；不要自动渲染——用户没提 `--render` 就不动
- PDF 渲染（xelatex + TeX 发行版）依赖较重，默认不做；用户确有打印需求时再单独处理
